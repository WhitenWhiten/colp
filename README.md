# The Collection Protocol (COLP)

An open protocol for bookmark and knowledge collections, with a Node.js implementation.

- [`protocol/`](protocol/README.md): specification, JSON Schema, and examples.
- [`packages/node/`](packages/node/README.md): `@collection-protocol/node`, tests, and integration docs.

```sh
npm run install:package
npm run build
```

Development snapshot; npm publication and standalone release evidence are pending.
