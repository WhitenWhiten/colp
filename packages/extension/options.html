                    Your AI service

                    Advanced service settings

                    A custom endpoint must speak the System One classification API. Test connection checks this.

                    Plain HTTP on a local address sends the token and bookmark text unencrypted. Use it only for a classifier you run yourself.

                    Keep your TypeSafe key in your own Cloudflare AI Gateway (alias "default"). The extension only stores the Cloudflare token.

                    What is sent

                    The page's URL and title, your folder names and descriptions, and a few bookmark titles and domains from each folder. Tag names are included when a collection is synced. Know-N never sees the request or the reply. The key stays on this browser and is never synced.
