Contact Know-N

There is no public telephone number and no public mailing address for Know-N today. This site does not list a switchboard, a postal box, or a street office that can receive account mail. If a directory, form, or agent asks for a telephone number or a mailing address, the honest answer is that none is published.

How to reach the project

The public channel for product discussion, defects, and documentation gaps is email: help@know-n.com. Write there for questions about the product, a broken public reading path, or a problem in the browser extension. Do not send passwords, recovery codes, session cookies, or the contents of a private collection.

Know-N publishes that mailbox on this page. There is no phone line and no postal address to write to. Maintainers read mail sent to help@know-n.com; that is the channel that exists today.

What this page is for

This page exists so guests and crawlers can see how to talk to the people who maintain Know-N. It is not a help desk that can reset someone else's account from a public form. Account holders who are already signed in use Settings and Account for profile and session controls. Those screens are not a substitute for writing to help@know-n.com when the topic is the product itself.

If you found a broken public reading path or a problem in the browser extension, email help@know-n.com with the URL and what you expected to happen. If a topic cannot be public, say so in the message without including secrets. Maintainers can continue the conversation by email rather than through an unpublished phone line or mailing address.
