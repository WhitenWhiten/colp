# Upstream

Copied from Know-N commit `c34645710eb3d0067ef734cf7a674364df765687` (`Known-Frontend/web`) on 2026-10-07.

The package name stays `known` (`private: true`). Neither 02-plan.md nor the C1 card renames it to `@know-n/colp-web`. License: Apache-2.0.

The copy first hid the hosted-service surfaces behind `VITE_EDITION=self-hosted`. On 2026-10-11 the package became self-hosted only: the edition switch is gone, and the routes, components, API clients, styles, tests, and e2e specs for those surfaces were deleted instead of gated. Removed: Explore, public profiles (`/u`, `/profile`), follow (`/library/following`), Today and activity, the feed, notifications, comments and votes, moderation and reports, digests, credits, AI organize, Classify, admin, share and embed pages, reading paths and the Reader, the trust and developer pages, the demo tree, export jobs, onboarding, password reset, email verification, saved resources and reading progress, link previews, favicon upload, and the marketing landing page. `src/lib/edition.ts` keeps `productName()`, `brandedTitle()`, the D8 browser-subscription gate, and the registration-state parser. Search asks only for collections, bookmarks, and annotations, because profiles have no page here.

The self-hosted server sends no email, has no sign-in providers, and has no object storage (D28). `/login` renders `SelfHostedLogin` (username or email plus password, `POST /api/v1/auth/sign-in/username` when the identifier has no `@`, and a pointer to `colp-server reset-password`). `/register` reads `GET /api/v1/auth/registration-state` and shows sign-up only when `open` is true (`first-run` owner form, `invite` form, otherwise a closed notice). `/` redirects to `/library` or `/login`. Settings has no Favicon, Notifications, or Privacy sections, no avatar upload or profile About, and under Security no email verification, email change, provider linking, or email-code re-auth. Subscribe to bookmarks stays hidden until D8. Agents (C3) replace the MCP page; the insecure-transport banner (C4) is mounted in `Layout` so every page, including sign-in, shows it.

The self-hosted design lives in two places, both scoped to `<html data-edition="self-hosted">` (set in `index.html` and again in `main.tsx`): the edition tokens at the end of `src/styles/tokens.css` (sans headings at a tool scale; Know-N's grain and hero wash stay) and `src/styles/edition.css`, the `edition` cascade layer between `utilities` and `print`. Colours, lines, and shadows are Know-N's; the edition overrides no colour token and recolours no component. When porting an upstream CSS change, port it to the matching file as usual; only touch `edition.css` if the change alters a surface the edition restyles. The brand mark is `public/colp-mark.svg` in Know-N ink, also used as the favicon.

`index.html` carries a neutral `COLP Server` head with `noindex` and the `<!-- agent-public:start/end -->` markers that the server's public shell fills. `public/` holds only the icons and a `robots.txt` that disallows everything; `npm run build` is `typecheck` plus `vite build`, with no post-build step.

`e2e-real-stack/`, `playwright.real-stack.config.ts`, and the `test:e2e:real-stack*` and `test:phase5:*` scripts were removed: they ran Know-N's `Known-Backend/scripts/real-stack-e2e.mjs` harness, which this repository does not ship, and most specs covered modules A2 deleted (feed, follow, notifications, community, governance, reading progress, public profiles). They stay in Know-N.

`@known/product-v1` is generated from `packages/server/openapi/colp-server-v1.yaml` by `npm run generate:api-types` (`scripts/generate-openapi-types.mjs`). The script reads that server document directly; nothing is copied into this package. Output is `src/generated/colp-server-v1.ts`, re-exported by `src/generated/product-v1.ts`. `@known/product-v1-client` still aliases `packages/server/generated/openapi/product-v1.client.ts`, the full Known client the server generator (`packages/server/scripts/generate-openapi.mjs`) builds from `openapi/product-v1.yaml`; the UI imports only the factories for operations this server serves. Operations marked `x-colp-server-pending` have no UI callers.

`upstream-fixtures/` holds the Know-N files the copied unit tests read by relative path: the Phase 2B annotation and relation acceptance notes and Known-Extension `popup.css`. They are not part of the self-hosted product.
