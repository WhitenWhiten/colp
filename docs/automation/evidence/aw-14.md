# AW-14 — ordered durable ingestion

> The final semantic/default corrections and overall acceptance are in [AW-66](aw-66.md); this record keeps the actual results when the task was committed.

Parent commit 027eecd. Each canonical commit appends a static automation_ingest route in the Outbox's last phase,
delivery_each_event / durable; the payload only has collectionId/operationId. Configures the production worker's registration,
closed envelope validation and route durability/readiness fields. A 5-second availability delay leaves grace for later device receipts.
(After review, the route is appended only while `KNOWN_FEATURE_AUTOMATION_CAPTURE` is on.)

Consumes up to the delivered stable ordinal in the transaction order account → source position → consumer → lease; at most
200 operations each time, including operations without facts, with overflow rescheduled through the existing continuation. Ordinal gaps are never guessed
from the number of matching facts. A unique operation-facts index removes multiple representations of the same canonical operation.
Failing the final lease generation, event identity or validity check rolls back the consumer and the cursor.
This commit's production consumer only performs durable inspection; AW-15 hooks up admission. Run capability stays unavailable.

Actual verification: server typecheck, check:imports, check:migrations -- HEAD (the new migration is above the original head),
ESLint on new files and git diff --check passed.
Real PostgreSQL source-position.integration.test.ts passed two cases: concurrent duplicate delivery including a fact-less bootstrap,
and rollback on an invalid lease followed by a successful retry. Test containers were reclaimed. An attempted old router.test.ts path does not exist and is not
recorded as passing; only the related database verification above was run.
