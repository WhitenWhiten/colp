# AW-24 — typed proposals and the existing Plan coordinator

基线 `4bfd189`；设计 `0.2.1-design`。`202610301200` 增加 durable proposal 和 version linkage。
输入闭合 schema、task/output contract 和 pinned source evidence 在进入 job 锁前验证。
随后校验当前 Owner/target、generation/token、input digest/resource revision 和 live folders。
模型只能提交 typed output；服务构造单一可逆 move、tags union 或 attributed note create/update，
拒绝越界 placement。metadata/review/digest 等无 canonical effect 的 typed output 无伪造 plan。

先事务保存 proposal/result、稳定 plan ID、command ID、canonical operation ID 和 committing，
再在事务外调用现有 COLP change-plan service 和 production coordinator，最后短事务链接
canonical operation、pre-commit version、effect receipt 和 accepted job。未知提交结果保留
committing；恢复查找同一个 plan，不重新规划。Manual 使用现有 Approvals，Trusted 复用
现有 agent policy、版本、审批、digest/revision/scope/rate-limit 路径。

Host 私有 registered operations 扩展既有 executor；不拓宽冻结 COLP generic changes.plan
operation enum。所需权限是实际 automation:work，不为 worker 发明 nodes:write/manager
权限。生产 coordinator 的 beforeBeginCommit 接受同一当前 job authority guard（AW-31 挂载）。
Annotation ports 从既有 adapter 提取以加入现有 coordinator 的事务；原 annotation UoW
仍保留 receipt/canonical invariant guards。已存在 note 追加内容和 attribution，不替换用户文本。

修复同一真实 crash 窗口：Trusted 已先捕获版本时，commit hook 仍须在提交事务内写入
version receipt，不能因发现 prior snapshot 就跳过，从而避免 commit 后 helper 尚未保存
receipt 的进程崩溃丢失历史关联。

  Typed suite 7 项涵盖现有 Owner Approvals、Trusted note/tags/move、exact repeat、提交前/后
  crash、same plan recovery、note append、错误 contract/source、newer manual edit。

  BE-2 新增 automation Outbox 后旧 create 计数未同步，更新为 ledger=6/outbox=3，并明确验证
  新路线 handler/type/redacted payload。不是放宽重复效果断言。

  digest shape 错误，修正真实 fixture 后才计入通过；没有把这些失败当作产品反例。
