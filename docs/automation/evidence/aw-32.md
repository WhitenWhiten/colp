[connection/recovery guide](../agents.md). The worker authenticates with externally
supplied existing tokens, redeems the Owner grant, selects one target, drains queue
and input pages, claims, heartbeats and submits the declared typed result. Provider
modules see only task/allowlisted input, without credential or lease access.

restart. Interrupted external work reports unknownOutcome; claim conflicts are
skipped without another call. CLI errors redact server/provider bodies and output
only job/status. HTTP permits TLS or loopback and refuses redirects.
