结果 → exact-preview enable/暂停/归档 → dependencies/health/incidents。配置 enabled 的实际状态

audit、outbox、facts、run、job 或 effect 写入。集成测试验证了这些表计数。

pg_dump/pg_restore、restore.sh 实际暂停 SQL 与无秘密 portable export 已验证。
