# AW-23 — fenced claims, heartbeat and uncertainty

基线 `eabf2c8`，设计 `0.2.1-design`。新增 `202610301100` job pins/lease migration。
短事务内锁定当前 active Account、Owner collection、未取消/未 hold 的 run/job；
TargetAuthority 是必需的当前权限端口，AW-26/31 挂载真实配对权限与传输。
Claim 默认 120 秒，token 只存 SHA-256，generation 单调；heartbeat 最长续 120 秒，
参考 worker 每 30 秒调用。token 不代替认证，错误 credential binding、旧 generation、
失去 Owner、撤销账户、hold、pause 都不能完成。list/claim 的 HTTP 503/Retry-After
在 AW-31 统一挂载，当前应用错误已集中登记 automation_paused=503。

knownRetryable 允许下一 generation（仍受 maxCalls/caps 约束）；permanent 失败；
unknownOutcome 和过期 lease durably 进入 uncertain，不自动重试。过期转换先提交再
返回冲突，避免异常回滚把 uncertainty 丢失。外部调用许可在 claim 记账，不能当作模型
成功或已知费用；后续 read model 必须保留这一含义。
