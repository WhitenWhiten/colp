# AW-22 — execution policy, optional budgets and reuse identity

Baseline `93f6d68`; design `0.2.1-design`; adds Product `1.96.0` and keeps the frozen 1.95.0.
The new migration `202610301000` sorts after the actual `202610300900`; no Events/M3 tables.

Policy CRUD reuses the Owner session, Origin/CSRF, strong ETag, command receipts and the configuration transaction,
storing immutable revisions. Duplicate task assignments are rejected; an uninstalled automatic fallback is explicitly unavailable.
Without a policy/assignment, or when fields exceed allowedData, optional calls are not permitted. Budgets are reserved atomically per UTC day,
with a default of 100 distinct runs per rule and an explicit server cap; duplicate jobs/runs are not charged twice.
Call counts are accounted per rule/target and external cost starts unknown. The M1 executor neither reads these tables nor is blocked by the caps.
The reuse identity contains the Owner, input digest, contract and current authority digest; unaccepted results are not reusable.
These services are called by the worker orchestration of the later AW-23/31; this task does not claim a complete worker is installed.
