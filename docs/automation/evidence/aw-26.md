# AW-26 — target profiles and authenticated worker pairing

基线 `ac79c62`；设计 `0.2.1-design`。单调迁移 `202610301300` 引入 profiles、targets、
external executors、一次性 pairings，基于实际 `202610301200` head；不创建 Events 表。
Owner CRUD 复用 Session/Origin/CSRF/ETag/command receipts。独立 catalogs 不隐含权限。
每个 target 建立 external executor 身份；未验证的 agent task capabilities 保持空，
serverModel/browser executor 明确 unavailable。

HTTP `/api/v1/automation-work/pairings/claim` 在生产 composition 复用现有 MCP OAuth
verifier（含 account-key token exchange）、当前 account/credential/ancestor/server epoch
和共享 MCP rate limiter。bootstrap 只需要 automationWorker opt-in + automation:work，
不需要 manager scope。Grant 五分钟、哈希存储，绑定 Owner、target generation、profile
revision、预期 client/credential identity，原子单次消费。同一 command 安全重放前仍校验
当前权限；新 command 重放已消费 grant、外来身份、过期/旧配置授权均拒绝。

一次性 code 不写入普通 command receipt：按现有 account credential 签发约定，重放
Owner issuance 的 code=null；契约调整明确此语义，丢失初始响应需签发新 grant。
Worker 返回的 profile observation 严格白名单，仅 token-free identity/digests/epochs，
不序列化任意 actor/request。Owner target view 也重新校验凭据，撤销/过期不能继续 active。

OAuth shared binding 不支持 restricted work。真实独立 child-key 的稳定 binding（含祖先
和 account epochs）且只分配一个 target 才有 dedicated isolation；当前 pinned rule privacy
也传入授权，不因 target 后续改为 standard 放宽旧 restricted job。Polling readiness 表示
有权轮询，不保证 worker 已被部署或定时。Events 只有 waiting/unavailable，不从 URL、
Owner 开关或 AW-02 的实验推断生产 readiness。AW-53 契约 fixtures 在 fixtures/aw-26；
其中 active 仅 polling，reachability fixture 明确 capability unavailable，不伪造网络探测。
