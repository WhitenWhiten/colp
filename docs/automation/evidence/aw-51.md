# AW-51 — verified placement history and conservative Undo

父提交 4167980。设备已验证 placement 现在记录独立 effect receipt，固定 canonical operation、
前后 resource revision、原目录（可证明时）、提交时 content revision 和效果 digest。
getAutomationRun 返回有界效果及动态 undoAvailable/reason；无 Agent/target/policy。
新增 undoAutomationRun，通过已有 Owner cookie/CSRF/command/If-Match 入口，单事务重新锁定
当前 Owner collection、核对 resource/content/destination fences，执行一条 compensating canonical
move 并标记 receipt reverted。不会删除 create，不做整集合 snapshot restore。

实际验证：typecheck、check:imports、ESLint、git diff --check、openapi:ci 通过。

1. pre-save 无原目录证据时解释不可 Undo；
2. create→move 的单效果可补偿，HTTP 命令重放仅一条 undo operation，书签内容仍在；
3. 后续 Owner 手动移动使旧 Undo 返回 conflict，保留新位置。
没有浏览器或模型调用；测试容器已回收。server-intake 接入此 effect/Undo 机制由 AW-33 完成。
