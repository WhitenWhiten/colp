# AW-55 — waiting work and budget read model

Baseline `cae18f6`, branch `feat/colp-automation`, contract `0.2.1-design` with
additive producer adjustments. Field semantics are documented in
[ADR-BE1](../ADR-BE1.md#aw-55-waiting-work-and-cost-observations).

Rule detail/list and Run detail/list now expose authorized fixed-size scalar
aggregates: actual job states, held/blocked/budget/approval/uncertainty, distinct
UTC-day rule reservations and remaining rule allowance, optional attempts and
reported/unknown external costs. Run views also include their bounded job/target
identities. Current collection ownership filters private execution history.
Delivery capability is unavailable with null accepted deliveries before AW-29.

Migration `202610301600_automation_cost_observations.ts` adds a nullable per-attempt
cost. Existing attempts stay unknown. The first result reports cost once against
the original call day; duplicate commands/results cannot increment it twice.
Worker reports are explicitly unverified observations, not enforceable provider
spending. No secret/body/provider reference is projected into usage.
