canonical 顺序增加必需 facts port，位于 audit 和 outbox 之间。生产适配器在持有集合锁的
planning 阶段保存前后 URL/title/tags/parent/ancestor identity；capture 只消费计划和分配结果，
不重新读取节点。祖先上限 128；超限/断链明确 ancestryComplete=false，不伪造完整事实。
私有表不保存 description、readable content、extensions 或 credentials；通用事件不增加事实载荷。
Web、MCP、Sync 入口带服务端 provenance；显式 import/restore/automation context 由内部调用者绑定，
不从用户 resource DTO 推导。当前仓库没有独立 Product import endpoint；import 调用者可通过
canonical unit-of-work 的 automationOrigin='import' 绑定。未知内部写入保持 system，不能猜成用户新建。
事实 source_event_id 使用同一事务分配的 canonical domain event identity。
