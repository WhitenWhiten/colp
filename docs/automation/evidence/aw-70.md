# AW-70 — web: fill the rule editor from a browser rule

Built on AW-69 (`e0ad3583`) on `main`. Design [01 §7.5](../design/01-architecture.md#75-browser-rules-adr-a24-au-34),
story AU-34; acceptance AC-72.

## What shipped

`/automations/new` already took `collectionId` and `folderId` (Automate… on a folder). It now also takes what
the extension's *Add mine to the account* (AW-71) sends from a browser rule, through `draftFromSearch` in
`packages/web/src/pages/automations/ruleDraft.ts`:

- `name` (trimmed, at most 200 characters), `combinator` (`any`, else `all`);
- repeated `condition=kind:value`, split at the first colon so a value may contain one. Kinds are the form's
  own; an unknown kind, an empty value or one over 512 characters is dropped; at most 8 are kept. With none
  left, the form keeps its one empty row;
- `from=browser` adds one status note above the form: "Filled in from a rule in your browser. Preview it, then
  turn it on to use it on every device."

It is only a form. Nothing is created until the Owner saves, and *Turn on* still needs a preview of exactly
this rule (AU-02). No API operation was added.
