# AW-27 — pinned Events adapter and durable subscriptions

Local implementation on `feat/colp-automation`, contract `0.2.1-design`, SDK 2.3.1.
The existing authenticated MCP envelope dispatches Events methods, gated by
`KNOWN_FEATURE_MCP_EVENTS`, worker scope, current profile and paired target.
Discovery explicitly preserves the pinned empty Events capability; draft methods,
replay cursors, pairing codes and invalid callback/secret inputs fail closed.

Subscriptions have a stable principal/target/callback identity and finite 1-minute
minimum / 1-day maximum TTL (default 1 hour). Verification runs outside locks;
activation rechecks current authority, profile/pairing pins and reserved generation.
Refresh and unsubscribe preserve identity; stale verification cannot resurrect a
cancelled subscription. Migration 202610301800 follows actual head 202610301700.

- PostgreSQL `events-subscriptions.integration.test.ts`: 3 tests passed, covering
  restart/refresh identity, TTL, cancellation race, verification failure and revocation.

  Node 22/npm 10 (Node 24/npm 11 correctly rejected manifest generation).
